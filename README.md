# 📘 Ver-1 仕様書：代換提案機能つきレシピサイト

## 🌟 目的
ユーザーが持っていない「材料・器具」をチェック式で選択し、AIを活用して代換案と手順の修正を提示するレシピ支援サイトを実装する。

---

## 🧑‍🍳 代替提案付きレシピデモサイト

このプロジェクトは、**持っていない材料や器具をチェックするだけで、代替案とそれに応じたレシピ手順を提示してくれる**レシピサイトのプロトタイプです。

## 🕹️ 使い方

1. **レシピを選択**  
   画面上部のドロップダウンからレシピを選びます。

2. **持っていない材料・器具をチェック**  
   チェックボックスで、自分が「持っていない」ものを選択します。

3. **代替案を表示**  
   オレンジの「代替案を表示」ボタンをクリックすると、該当する材料や器具に対して代替案が提案されます。  
   例：牛乳 → 水＋ヨーグルト

4. **レシピ手順の自動書き換え**  
   手順中の対象材料に応じて、打ち消し線＋新しい代替手順が表示されます。

---

## 🧪 機能一覧（実装済み）

| 機能             | 説明                                                                 |
|------------------|----------------------------------------------------------------------|
| 材料・器具リスト   | チェック式で「持ってないもの」を選択可能                                    |
| 代替案取得        | OpenAI API へのプロンプト送信 → 整形して取得                                |
| 代替表示          | マッチした材料の下に「→ ○○で代用可能」と表示                             |
| 手順書き換え       | 手順が変更されていたら、打ち消し線付きで旧手順＋新手順を表示                    |
| デバッグ表示      | `console.log` で key マッチングログを出力可能                            |

## 🧾 レシピデータのJSONフォーマット

`data/recipes.ts` に記述されている各レシピは、以下の構造を持つオブジェクトです：

### 📦 JSONデータ構成（ティラミスの例）

| フィールド名     | 型           | 説明 |
|------------------|--------------|------|
| `id`             | `string`     | レシピの一意な識別子（URLや内部参照に使用）例：`tiramisu` |
| `title`          | `string`     | 表示用のレシピタイトル 例：`本格ティラミス` |
| `category`       | `object`     | メインカテゴリとサブカテゴリのオブジェクト |
| └─ `main`        | `string`     | 上位カテゴリ 例：`お菓子` |
| └─ `sub`         | `string`     | 下位カテゴリ 例：`冷たいお菓子` |
| `ingredients`    | `Array`      | 材料一覧。各要素は `{ key, label }` のオブジェクト |
| └─ `key`         | `string`     | 材料の識別用キー（代替候補判定などに使用）例：`マスカルポーネ` |
| └─ `label`       | `string`     | 表示用の材料ラベル 例：`マスカルポーネチーズ 200g` |
| `tools`          | `Array`      | 使用する器具一覧。構造は `ingredients` と同様 |
| └─ `key`         | `string`     | 器具の識別用キー 例：`ボウル` |
| └─ `label`       | `string`     | 表示用の器具ラベル 例：`ハンドミキサーまたは泡立て器` |
| `steps`          | `string[]`   | 調理手順の配列。各要素が1ステップに対応。順序通りに処理 |


---

### 🧾 レシピ定義の例：**食パン**

```ts
{
    id: 'tiramisu',
    title: '本格ティラミス',
    category: {
      main: 'お菓子',
      sub: '冷たいお菓子'
    },
    ingredients: [
      { key: 'マスカルポーネ', label: 'マスカルポーネチーズ 200g' },
      { key: 'エスプレッソ', label: 'エスプレッソ 100ml' },
      { key: '卵黄', label: '卵黄 2個分' },
      { key: 'グラニュー糖', label: 'グラニュー糖 大さじ2' },
      { key: 'カステラ', label: '市販のカステラ 適量（約100g）' },
      { key: 'ココアパウダー', label: '純ココアパウダー 適量（仕上げ用）' },
    ],
    tools: [
      { key: 'ボウル', label: 'ボウル' },
      { key: 'ハンドミキサー', label: 'ハンドミキサーまたは泡立て器' },
      { key: 'エスプレッソマシン', label: 'エスプレッソマシンまたはコーヒーメーカー' },
      { key: 'ヘラ', label: 'ゴムベラ' },
      { key: '器', label: '容器またはグラス' }
    ],
    steps: [
      'ボウルに卵黄とグラニュー糖を入れ、ハンドミキサーで白くもったりするまで泡立てる。',
      'マスカルポーネを加えてさらによく混ぜ、滑らかなクリーム状にする。',
      'カステラを1cm厚にスライスし、容器の底に敷き詰める。',
      'エスプレッソをカステラに均一に染み込ませる。',
      'その上にクリームを流し入れ、表面をヘラでならす。',
      'これを2層程度繰り返し、最後はクリームで終える。',
      '冷蔵庫で3時間以上冷やし、仕上げにココアパウダーをふる。'
    ]
  },
```
